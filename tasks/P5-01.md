## Phase

P5

## Objective

Write the decision Andu accepted on 2026-11-13 (Asia/Hong_Kong) into [ADR-0010](../docs/adr/0010-local-greek-htr-runtime.md) and close the three questions that hard-blocked P5. Leave the recognizer unbuilt.

## Problem

[ADR-0010](../docs/adr/0010-local-greek-htr-runtime.md) was Proposed and blocked. [Q-SCI-04](../docs/OPEN_QUESTIONS.md#q-sci-04), [Q-SCI-14](../docs/OPEN_QUESTIONS.md#q-sci-14), and [Q-ENG-03](../docs/OPEN_QUESTIONS.md#q-eng-03) still named an unchosen hand scope, an unchosen model, and an unchosen runtime. Later HTR work could not start while those three stayed open. The storage rules for Greek text were already decided and did not need a new schema.

## User or scientific outcome

A later ticket author can see the accepted runtime, the named weight file, its license, the published checksum, and the download rule, and can see which questions remain open. A scholar still has no HTR command in this checkout.
