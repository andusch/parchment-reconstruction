A later ticket author can see the closed policies. Language scoring may use supplied letters only with an explicit label and a recorded treatment. Training on scholarly restoration stays forbidden. Language still does not create a join that geometry rejected. The accepted default sort is a declared weighted sum in the parameter blob, with `physical`, `htr`, and `language` still stored separately. This ticket leaves the scholar without a language score and without a fused sort.
