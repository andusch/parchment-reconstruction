## Title

## Phase

P0

## Objective

Check that the architecture names the headless layering and that six scoped rules enforce the resolved model. Fix only a mismatch between a rule and the data model.

## Problem

Later agents implement against the architecture and the Cursor rules. A rule that still stores status on a hypothesis row, treats a reading as observed, or allows ground truth in the project database will undo the review.

## User or scientific outcome

An implementer can see which layer owns ingest, frames, and provenance, and which rule forbids a fourth epistemic class, a status column, or a solver read of `benchmarks/`.
