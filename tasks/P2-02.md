## Title

Read samples from the synthetic uncompressed TIFF layout only.

## Phase

P2

## Objective

In about one day, recover width, height, and grayscale samples from bytes written by the P1 fixture writer, and refuse every other layout.

## Problem

Segmentation needs pixels. [Q-ENG-05](../docs/OPEN_QUESTIONS.md#q-eng-05) has not approved a TIFF library. The fixture writer already emits one uncompressed grayscale layout, and the package cannot yet read those samples back.

## User or scientific outcome

A benchmark operator can take a fixture TIFF and recover its samples, or receive a structured failure for any other layout. The failure is not an outline.

## Inputs

- The uncompressed grayscale writer in [src/prw/synthetic_tear.py](../src/prw/synthetic_tear.py), including `TIFF_WIDTH_OFFSET`, `TIFF_HEIGHT_OFFSET`, decoder name `synthetic_uncompressed_tiff`, and decoder version `1`.
- The TIFF magic check from [P1-05](P1-05.md).

## Outputs

- A reader that returns samples, width, and height for that layout.
- A structured failure for any other byte string. The failure carries no outline and no hypothesis.

## Epistemic-class impact

no. Samples are bytes from a synthetic fixture. A layout failure is a protocol result with no epistemic class.

## Stop and ask

Answer each line `yes` or `no`. Any `yes` blocks implementation until a decision exists.

- Changes a public API: no
- Changes the project format: no
- Changes the privacy policy ([SECURITY_AND_PRIVACY.md](../docs/SECURITY_AND_PRIVACY.md)): no
- Changes evidence semantics (text status, epistemic class, or the meaning of a hypothesis): no

## Schema impact

none. The reader writes no project directory and no `originals/` copy.

## Algorithm and benchmark impact

none. The reader does not segment and does not score a solver.

## New dependencies

none. No Pillow and no NumPy.

## Acceptance criteria

- [x] A TIFF just written by the fixture generator round-trips to the same width, height, and samples.
- [x] TIFF magic with a different IFD, a compressed strip, or a non-grayscale photometric tag fails and produces no polygon.
- [x] Tags 282 and 283 are not read. Header PPI does not become `pixels_per_mm`.
- [x] The decoder name and version match the writer: `synthetic_uncompressed_tiff` and `1`.
- [x] About one day. No network call.

## Tests

Generate a fixture TIFF in a temporary directory and read it back. Cover a matching round-trip, a rewritten IFD, a compression tag other than uncompressed, and a photometric tag other than grayscale. Assert the failure is not an outline. Do not read repository TIFF files, `data/`, `scans/`, or `real_data/`.

## Provenance effects

The reader exposes decoder name `synthetic_uncompressed_tiff` and decoder version `1` for a later envelope. It does not write an outline envelope.

## Non-goals

- Closing [Q-ENG-05](../docs/OPEN_QUESTIONS.md#q-eng-05). This reader is the fixture layout only.
- Segmentation ([P2-03](P2-03.md)). Copying bytes into `originals/`.
- An accuracy claim against human outlines. [Q-SCI-17](../docs/OPEN_QUESTIONS.md#q-sci-17) stays open.
- Ruling, pricking, and hair/flesh side. [Q-PRD-10](../docs/OPEN_QUESTIONS.md#q-prd-10) stays open.
- A geometry library. [Q-ENG-04](../docs/OPEN_QUESTIONS.md#q-eng-04) stays open.
- Qt, a network call, and a new runtime dependency.
- Reading `data/`, `scans/`, `real_data/`, or model weights.
- A solver path that reads the BenchmarkLabel store. Project entities do not gain `truth`, `correct_join`, or `original_text`.
- Adding `outline_ids` to `AlgorithmRun`.

## Required documentation

- The docstring cites the writer layout in [src/prw/synthetic_tear.py](../src/prw/synthetic_tear.py) and [Q-ENG-05](../docs/OPEN_QUESTIONS.md#q-eng-05).
- State that this reader is not an approved decoder for arbitrary scans.
- Do not add the reader to [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) as a general image library.
