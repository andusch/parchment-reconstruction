## Title

Report character error rate on a frozen synthetic line fixture under the Q-SCI-16 policy.

## Phase

P5

## Objective

Add an unfrozen headless command that reports character error rate under the abbreviation policy frozen by [P5-03](P5-03.md). The first number is a synthetic-fixture result.

## Problem

[P5-01](P5-01.md), [P5-02](P5-02.md), and [P5-03](P5-03.md) are Done. The recognizer stores Unicode NFC `ocr_inferred` graphemes and writes no score. [Q-SCI-16](../docs/EVALUATION.md#q-sci-16) is closed. P5's remaining official exit criterion is a workbench character-error number reported only after that policy was frozen. The policy was frozen before this run.

## User or scientific outcome

An operator can write the frozen synthetic line fixture and a character-error report with `prw character-error`. The report lists every line. Lines tagged `nomen-sacrum`, `abbreviation`, or `mixed-script` stay unscored. Every other line is compared as written, after accent stripping and final-sigma normalization, without expanding abbreviations and without rewriting stored NFC text. The scored total on that fixture is edit distance 1 over reference length 22. That number does not measure Ancient Greek handwriting, scholarly acceptability, or the PP-OCRv6 medium model card.

## Inputs

- The abbreviation policy frozen by [P5-03](P5-03.md), approved by Andu on 2026-11-14 (Asia/Hong_Kong).
- A frozen synthetic line fixture: small uncompressed TIFF slots and `kind: line` rows in the BenchmarkLabel store. The slots encode code points. They are not handwriting.
- The reporting fields in [EVALUATION.md](../docs/EVALUATION.md#reporting).

## Outputs

- Unfrozen `prw character-error`. It is not a stable interface.
- `--generate-fixture` writes the line images, the image manifest, and BenchmarkLabel rows once. It does not score.
- A later invocation reads those labels and writes `benchmarks/character_error/character-error-0001.json`. The first report states that no previous character-error report exists.
- The synthetic reader is `synthetic_line_slots` version `1`. `model_hash` is `absent`. `random_seed` is absent. The scored total is edit distance 1 over reference length 22.
- `--model` can score `greek_line_htr` when the `htr` group is installed and the path is a local `medium.safetensors`. That path does not download weights. The default tests do not run it. A result from it is still a synthetic-fixture result and is not the model-card figure.

## Epistemic-class impact

no. A machine reading stays `interpretation`, producer `machine`, text status `ocr_inferred`. This command does not re-type a reading. Supplied text stays on a scholarly restoration. The report is a benchmark file, not a project entity, and it has no `correct_join`.

## Algorithm and benchmark impact

The new reader `synthetic_line_slots` version `1` decodes the fixture slots. It is deterministic and uses no model. The character-error report is the benchmark comparison. The first report on the frozen fixture records that no previous character-error report exists. A later report names the previous file and copies its line list. Solver paths and `recognize` do not read the BenchmarkLabel store. The card's cited Ancient Greek CER 7.21% and WER 44.03% stay citations and are not compared with this figure.

The tests do not read `data/`, `scans/`, `real_data/`, TIFF sources from a real corpus, or model weights. `uv run pytest -m "not slow"` covers the metric, the exclusions, the comparison normalization, and the command. ## Provenance effects

The synthetic report copies `synthetic_line_slots` version `1`, the full parameter blob and its `sha256:` hash, `code_version`, `model_hash` `absent`, decoder `synthetic_uncompressed_tiff` version `1`, and the source hashes of the line images. `random_seed` is absent because the reader is deterministic. The report also records the image-manifest hash, each manifest entry hash, and the `sha256:` freeze identifier of `labels.json`. A `--model` report copies `greek_line_htr` version `1` and the `sha256:` digest of the local weight bytes. No project run is written.
