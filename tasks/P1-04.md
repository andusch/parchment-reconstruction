## Title

Add CoordinateFrame and PageFrame records under the ADR-0011 axis convention.

## Phase

P1

## Objective

Create in-memory frame records that name kind, origin, and axes, including a centroid helper for `fragment_local_mm`, in about one day.

## Problem

Joins and overlays disagree when each caller picks an origin or a y axis. ADR-0011 fixes the convention. The package does not yet build a frame record.

## User or scientific outcome

A benchmark operator can build the three frame kinds and see the origin and axes on the record. A fragment-local frame stays put when a later outline revision is cited only as geometry, not as a new origin.

## Inputs

- [ADR-0011](../docs/adr/0011-frame-conventions.md).
- `CoordinateFrame` and `PageFrame` in [DATA_MODEL.md](../docs/DATA_MODEL.md).
- Content-derived ids from [P1-02](P1-02.md).

## Outputs

- In-memory `CoordinateFrame` and `PageFrame` values.
- A function that places the `fragment_local_mm` origin at the centroid of the cited polygon.

## Epistemic-class impact

no. A frame is a named coordinate system. It is not a reading and not a placement. Placements remain class `hypothesis` and are not created here.

## Acceptance criteria

- [x] A frame record stores `kind`, `origin_description`, `axis_x_direction`, `axis_y_direction`, and `unit`. Kinds are `source_pixels`, `fragment_local_mm`, and `page_global_mm`. Axes are `+x` right and `+y` down for all three. Unit is `px` or `mm` as the data model requires.
- [x] `source_pixels` origin is the top-left pixel. `fragment_local_mm` origin is the centroid of the polygon cited by `establishing_outline_revision_id`. That citation does not change when another outline id is supplied later. The mask is that polygon, not a `FragmentExtent`.
- [x] `page_global_mm` origin is the corner with the smallest x and the smallest y, at coordinate `(0, 0)`. `PageFrame` stores width and height as ranges. The ranges do not move the origin.
- [x] Transforms are not fields of a frame. The frame id is a UUIDv5 over the canonical content.
- [x] About one day. No network call.

## Tests

Synthetic polygons. A square from `(0, 0)` to `(2, 2)` has centroid `(1, 1)`. A second polygon does not change `establishing_outline_revision_id` or the origin. Page ranges do not change the origin. No project database.
