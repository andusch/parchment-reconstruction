## Title

Confirm algorithm stage contracts, the ADR index, the risk register, the open-question index, and the task-ticket template.

## Phase

P0

## Objective

Check that the remaining P0 documents agree with each other: stage inputs and outputs, ADR 0001–0012 statuses, risk entries, question IDs, and the ticket template. Fix only a broken cross-reference or a status that disagrees with the ADR file. Do not close an open question.

## Problem

The roadmap exits P0 when the document set exists, ADR statuses match the index, and question IDs match the owning documents. A stale link or a stage that still ranks fragments leaves the next phase blocked on paperwork rather than on a real decision.

## User or scientific outcome

A later ticket author can copy the template and can see which stage consumes which record, which questions are still open, and which risks apply before any solver runs.
