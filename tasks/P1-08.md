# Task ticket

- Status: Ready
- Phase: P1

A **yes** on any stop-and-ask field means the ticket waits until an ADR and an explicit decision exist. Open questions are indexed in [OPEN_QUESTIONS.md](../docs/OPEN_QUESTIONS.md). The glossary is in [DATA_MODEL.md](../docs/DATA_MODEL.md#glossary).

## Title

Add a headless CLI for ingest, frame creation, provenance, and fixture generation.

## Phase

P1

## Objective

In about one day, expose the P1 use cases through a CLI that does not import Qt and does not accept a project format.

## Problem

The roadmap exits P1 when the CLI calls ingest, frames, provenance, and the fixture generator without Qt. Those use cases are not reachable from a terminal yet. Command names are not a compatibility contract.

## User or scientific outcome

A benchmark operator can, from a terminal, hash a synthetic TIFF, print a frame's origin and axes, print a provenance envelope, and generate a fixture whose labels land under `benchmarks/`.

## Inputs

- Use cases from [P1-03](P1-03.md), [P1-04](P1-04.md), [P1-05](P1-05.md), [P1-06](P1-06.md), and [P1-07](P1-07.md).
- The headless-CLI rule in [ADR-0005](../docs/adr/0005-qt-shell-and-headless-core.md).
- The P1 exit criteria in [ROADMAP.md](../docs/ROADMAP.md).

## Outputs

- A console entry point that calls those use cases and prints their results.
- A test that invokes the entry point without a display.

## Epistemic-class impact

no. The CLI prints records the use cases already built. It does not relabel a hypothesis as observed or as truth.

## Stop and ask

Answer each line `yes` or `no`. Any `yes` blocks implementation until a decision exists.

- Changes a public API: no
- Changes the project format: no
- Changes the privacy policy ([SECURITY_AND_PRIVACY.md](../docs/SECURITY_AND_PRIVACY.md)): no
- Changes evidence semantics (text status, epistemic class, or the meaning of a hypothesis): no

## Schema impact

none. The CLI does not write `manifest.json` or `originals/`.

## Algorithm and benchmark impact

none beyond invoking the generator. The CLI does not score a solver and does not read BenchmarkLabel rows back into a ranking.

## New dependencies

none. Use the standard-library argument parser. No Qt binding.

## Acceptance criteria

- [ ] The CLI can verify a file and print either the content hash or an `IntegrityFailure`. A mismatch does not print a hypothesis.
- [ ] The CLI can print a `fragment_local_mm` frame whose origin is the centroid and whose axes are `+x` right and `+y` down, in millimetres.
- [ ] The CLI can print a provenance envelope that includes the parameter blob and the `sha256:` parameter hash. A deterministic call omits `random_seed`. The generator call includes it.
- [ ] The generate command writes images, the manifest, and BenchmarkLabel rows under caller-supplied paths. It refuses a destination inside a project evidence database. Ground truth is not printed as a `correct_join`.
- [ ] About one day. The process imports no Qt module and opens no network connection. Command names are documented as unfrozen.

## Tests

Invoke the CLI on synthetic bytes in a temporary directory. Cover a checksum mismatch, a frame printout, and a generate run that writes only under the temporary `benchmarks/` path. No display and no read of `data/`, `scans/`, or `real_data/`.

## Provenance effects

The CLI prints the envelope the use case built. It does not invent a second envelope.

## Non-goals

- A Qt shell, a worker thread or process, and off-thread progress. [Q-ENG-06](../docs/OPEN_QUESTIONS.md#q-eng-06) blocks the worker mechanism, not this foreground CLI.
- Accepting the ADR-0007 project layout.
- Freezing command names or flags as a public API.
- Detection, join ranking, HTR, and export.

## Required documentation

- A short CLI section in the package docstring or the README points at the four use cases and states that the project format is still [Q-ENG-01](../docs/OPEN_QUESTIONS.md#q-eng-01).
- Do not document the commands as a stable interface.

## Open questions this depends on

None must be closed first. Q-ENG-01, Q-ENG-05, and Q-ENG-06 stay open. The CLI does not close them.
