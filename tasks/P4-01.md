# Task ticket

A **yes** on any stop-and-ask field means the ticket waits until an ADR and an explicit decision exist. Open questions are indexed in [OPEN_QUESTIONS.md](../docs/OPEN_QUESTIONS.md). The glossary is in [DATA_MODEL.md](../docs/DATA_MODEL.md#glossary).

## Title

Store a page-frame placement pose and an in-memory assembly log.

## Phase

P4

## Objective

In about one day, store a machine rigid pose from `fragment_local_mm` into `page_global_mm`, and insert an `AssemblyContent` row with its first status event.

## Problem

A placement's destination is the shared page frame. `RigidTransform.create` in [src/prw/joins.py](../src/prw/joins.py) accepts only two `fragment_local_mm` frames. That constructor is the join-pose rule. `AssemblyContent` and `insert_hypothesis` already exist in [src/prw/provenance.py](../src/prw/provenance.py). No log yet stores those rows beside a page pose.

## User or scientific outcome

A benchmark operator can construct a machine placement into the project page frame, insert an assembly hypothesis, and read that row back with status `proposed` or a machine `rejected`. The join-pose constructor still accepts only two fragment-local frames.

## Inputs

- `RigidTransform`, `AssemblyHypothesis`, and `PageFrame` in [DATA_MODEL.md](../docs/DATA_MODEL.md#rigidtransform).
- `AssemblyContent`, `Placement`, and `insert_hypothesis` in [src/prw/provenance.py](../src/prw/provenance.py).
- `PageFrame` and `CoordinateFrame.page_global_mm` in [src/prw/frames.py](../src/prw/frames.py).
- The join-pose constructor in [src/prw/joins.py](../src/prw/joins.py).

## Outputs

- A new module, `prw.assemblies`. It holds `placement_pose` and `AssemblyLog`.
- `placement_pose` returns a `RigidTransform`. The source frame is `fragment_local_mm`. The destination frame is `page_global_mm`. The pose stores rotation and translation. Epistemic class is `hypothesis`. Producer is `machine`. The id is a UUIDv5 over that content. The caller supplies `provenance_id`.
- `AssemblyLog.insert` stores an `AssemblyContent` value and appends the first `StatusEvent` in the same write. The event is `proposed`, or `rejected` when the write is a machine rejection. The content row has no status column. A second insert of the same id is refused. `by_id` returns the stored row.
- `RigidTransform.create` still rejects a frame other than `fragment_local_mm`.

## Epistemic-class impact

no. A placement pose and an assembly are `hypothesis`, which the data model already assigns. This ticket does not re-type an outline, a join, or a reading, and it does not store a scholarly restoration.

## Acceptance criteria

- [ ] `placement_pose` returns a machine hypothesis whose source kind is `fragment_local_mm` and whose destination kind is `page_global_mm`. A pixel frame, a fragment-local destination, or a page-frame source is rejected. A class other than `hypothesis` is rejected. A producer other than `machine` is rejected.
- [ ] The pose stores rotation and translation. It has no scale field. Its id is a UUIDv5 over that content.
- [ ] `RigidTransform.create` still rejects a destination of `page_global_mm`.
- [ ] `AssemblyLog.insert` appends `proposed`, or `rejected` for a machine rejection, and `by_id` returns the same content. The content row has no status column. A second insert of the same id is refused.
- [ ] About one day. No assembly is searched. No polygon overlap is tested. No network call.
