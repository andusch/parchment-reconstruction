- Phase: P2

A **yes** on any stop-and-ask field means the ticket waits until an ADR and an explicit decision exist. Open questions are indexed in [OPEN_QUESTIONS.md](../docs/OPEN_QUESTIONS.md). The glossary is in [DATA_MODEL.md](../docs/DATA_MODEL.md#glossary).

## Title

Expose segmentation and outline agreement through the headless CLI.

## Phase

P2

## Objective

In about one day, call the P2 use cases from the existing console entry point without importing Qt.

## Problem

Core algorithms have to be usable without the GUI. Segmentation, the millimetre conversion, and outline agreement are not reachable from the terminal yet. Command names are not a compatibility contract.

## User or scientific outcome

A benchmark operator can, from a terminal, segment one synthetic fragment TIFF and print an IoU for polygons they pass in, with no display.

## Inputs

- Use cases from [P2-03](P2-03.md), [P2-04](P2-04.md), and [P2-05](P2-05.md).
- The CLI from [P1-08](P1-08.md).
- The headless-CLI rule in [ADR-0005](../docs/adr/0005-qt-shell-and-headless-core.md).

## Outputs

- Unfrozen commands that print an outline or an IoU report.
- The agreement command receives polygons from the caller. It can write the comparison under a caller-supplied `benchmarks/` path.

## Epistemic-class impact

no. The CLI prints records the use cases already built. It does not relabel an outline as observed or as the true boundary.

## Stop and ask

Answer each line `yes` or `no`. Any `yes` blocks implementation until a decision exists.

- Changes a public API: no
- Changes the project format: no
- Changes the privacy policy ([SECURITY_AND_PRIVACY.md](../docs/SECURITY_AND_PRIVACY.md)): no
- Changes evidence semantics (text status, epistemic class, or the meaning of a hypothesis): no

## Schema impact

none. The CLI does not write `manifest.json` or `originals/`.

## Algorithm and benchmark impact

none beyond invoking [P2-05](P2-05.md). The segment command does not read BenchmarkLabel rows. The agreement command does not feed those rows into the segmenter.

## New dependencies

none. Use the existing standard-library argument parser. No Qt binding.

## Acceptance criteria

- [ ] A segment command prints the interpretation outline and its envelope, or a failure with no outline. A checksum mismatch does not print a polygon.
- [ ] When the caller supplies `pixels_per_mm`, the printed outline is in `fragment_local_mm`. When they omit it, the printed outline stays in `source_pixels`.
- [ ] An agreement command refuses a BenchmarkLabel join file and does not feed labels into the segmenter.
- [ ] The process imports no Qt module. Command names are documented as unfrozen.
- [ ] About one day. No network call and no worker thread or process.

## Tests

Invoke the CLI on a generated fragment TIFF in a temporary directory. Cover a checksum mismatch, a segment printout, a scale printout, and an agreement run that writes only under the temporary `benchmarks/` path. A path that points at a BenchmarkLabel join file is refused. No display and no read of `data/`, `scans/`, or `real_data/`.

## Provenance effects

The CLI prints the envelope the use case built. It does not invent a second envelope.

## Non-goals

- A GUI. Closing [Q-ENG-06](../docs/OPEN_QUESTIONS.md#q-eng-06). The foreground CLI is not a worker.
- Freezing command names or flags as a public API.
- The blocked correction command from [P2-06](P2-06.md).
- An accuracy claim against human outlines. [Q-SCI-17](../docs/OPEN_QUESTIONS.md#q-sci-17) stays open.
- Ruling, pricking, and hair/flesh side. [Q-PRD-10](../docs/OPEN_QUESTIONS.md#q-prd-10) stays open.
- A general TIFF library and a geometry library. [Q-ENG-05](../docs/OPEN_QUESTIONS.md#q-eng-05) and [Q-ENG-04](../docs/OPEN_QUESTIONS.md#q-eng-04) stay open.
- A network call and a new runtime dependency.
- Reading `data/`, `scans/`, `real_data/`, or model weights.
- A solver path that reads the BenchmarkLabel store. Project entities do not gain `truth`, `correct_join`, or `original_text`.
- Adding `outline_ids` to `AlgorithmRun`.

## Required documentation

- Extend the package docstring in [src/prw/__init__.py](../src/prw/__init__.py) and the Headless CLI section of [README.md](../README.md) so they name the segmentation, scale, and agreement use cases.
- State that the new commands are unfrozen and that the project format is still [Q-ENG-01](../docs/OPEN_QUESTIONS.md#q-eng-01).
- Do not document the commands as a stable interface.
