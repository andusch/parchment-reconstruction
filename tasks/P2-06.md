# Task ticket

- Status: Done
- Phase: P2

A **yes** on any stop-and-ask field means the ticket waits until an ADR and an explicit decision exist. Open questions are indexed in [OPEN_QUESTIONS.md](../docs/OPEN_QUESTIONS.md). The glossary is in [DATA_MODEL.md](../docs/DATA_MODEL.md#glossary).

## Title

Record a human outline correction as a new interpretation revision.

## Phase

P2

## Objective

In about one day, store a scholar's correction of a machine outline as the row [ADR-0013](../docs/adr/0013-human-outline-correction.md) names.

## Problem

The phase goal accepts human corrections as new records. [ADR-0013](../docs/adr/0013-human-outline-correction.md) closed [Q-PRD-08](../docs/OPEN_QUESTIONS.md#q-prd-08): the correction is a `FragmentOutlineRevision` in class `interpretation` with `producer: human`. The product does not store that row yet.

## User or scientific outcome

A scholar's correction is a new row. The machine polygon and the source bytes stay as they were.

## Inputs

- [ADR-0013](../docs/adr/0013-human-outline-correction.md) and the closed question [Q-PRD-08](../docs/OPEN_QUESTIONS.md#q-prd-08).
- [ADR-0006](../docs/adr/0006-append-only-hypotheses.md).
- The machine outline from [P2-01](P2-01.md).
- `FragmentOutlineRevision` in [DATA_MODEL.md](../docs/DATA_MODEL.md#fragmentoutlinerevision).

## Outputs

- One new in-memory `FragmentOutlineRevision`. `epistemic_class` is `interpretation`. `producer` is `human`. `run_id` is null. `operator_id` and `session_id` are set. There is no machine envelope. `supersedes_id` cites the machine revision. Because `run_id` is null, the id is a UUIDv5 over `fragment_id`, `supersedes_id`, `operator_id`, `session_id`, and the polygon.
- The machine polygon stays. The caller-supplied source bytes stay. No `FragmentExtent` is stored.

## Epistemic-class impact

no. The class is the one [ADR-0013](../docs/adr/0013-human-outline-correction.md) named. This ticket stores that class. Acceptance does not re-type the machine outline.
