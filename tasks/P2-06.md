# Task ticket

- Status: Blocked
- Phase: P2

A **yes** on any stop-and-ask field means the ticket waits until an ADR and an explicit decision exist. Open questions are indexed in [OPEN_QUESTIONS.md](../docs/OPEN_QUESTIONS.md). The glossary is in [DATA_MODEL.md](../docs/DATA_MODEL.md#glossary).

## Title

Record a human outline correction as a new row once its evidence class is decided.

## Phase

P2

## Objective

After an ADR closes [Q-PRD-08](../docs/OPEN_QUESTIONS.md#q-prd-08), spend about one day storing the correction as a new record. Until that ADR, do not implement either option.

## Problem

The phase goal accepts human corrections as new records. [Q-PRD-08](../docs/OPEN_QUESTIONS.md#q-prd-08) leaves the evidence class open. Implementing either stored shape would decide that class without an ADR. The product does not store a correction class yet.

## User or scientific outcome

After the ADR, a scholar's correction is a new row, and the machine polygon and the source bytes stay as they were. Until the ADR, no correction row is stored.

## Inputs

- [Q-PRD-08](../docs/PRD.md#q-prd-08) and the same question in [OPEN_QUESTIONS.md](../docs/OPEN_QUESTIONS.md#q-prd-08).
- [ADR-0006](../docs/adr/0006-append-only-hypotheses.md).
- The machine outline from [P2-01](P2-01.md).
- The two open record shapes: a new `FragmentExtent` in class `observed`, or a new `FragmentOutlineRevision` in class `interpretation` with producer `human`.

## Outputs

- None until the ADR.
- After the ADR, one new in-memory row of the chosen type, linked so the machine polygon and the source bytes remain.

## Epistemic-class impact

yes. The evidence class of a human outline correction is [Q-PRD-08](../docs/OPEN_QUESTIONS.md#q-prd-08). This ticket does not choose it. Acceptance of a machine outline, if a later decision records one, does not re-type that outline.

## Stop and ask

Answer each line `yes` or `no`. Any `yes` blocks implementation until a decision exists.

- Changes a public API: no
- Changes the project format: no
- Changes the privacy policy ([SECURITY_AND_PRIVACY.md](../docs/SECURITY_AND_PRIVACY.md)): no
- Changes evidence semantics (text status, epistemic class, or the meaning of a hypothesis): yes

## Schema impact

none until the ADR, and none for the project directory after it. Records stay in memory. [Q-ENG-01](../docs/OPEN_QUESTIONS.md#q-eng-01) still blocks `manifest.json` and `originals/`. A stored schema change is a separate decision.

## Algorithm and benchmark impact

none. The correction is not benchmark ground truth. Solver code does not read BenchmarkLabel. This ticket writes no accuracy claim.

## New dependencies

none

## Acceptance criteria

- [ ] The evidence-semantics line above stays `yes`, and implementation does not start without an ADR that closes [Q-PRD-08](../docs/OPEN_QUESTIONS.md#q-prd-08).
- [ ] The machine outline's polygon is unchanged. The source bytes are unchanged. The correction is a new row.
- [ ] The new row uses only the class, producer, and type named in the ADR. The other shape is not also stored.
- [ ] A human outline revision, if that is the chosen shape, has a null `run_id` and sets `operator_id` and `session_id`. Acceptance does not re-type the machine outline.
- [ ] About one day after the ADR. No accuracy claim and no network call.

## Tests

No tests until the ADR exists. After it, synthetic in-memory records only. The machine polygon and a caller-supplied byte string stay unchanged. The unchosen shape is absent. Do not read `data/`, `scans/`, `real_data/`, or `benchmarks/` as ground truth.

## Provenance effects

A human outline revision has a null `run_id` and no machine envelope. A `FragmentExtent`, if that is the chosen shape, follows the provenance rule already on that type: an envelope only when the producer is `machine`. This ticket does not invent a third provenance shape.

## Non-goals

- Choosing the class inside this ticket. Editing the question index. Adding the ADR.
- Setting `identification_status: confirmed`.
- Overwriting a machine outline or source pixels. [ADR-0006](../docs/adr/0006-append-only-hypotheses.md) already forbids that.
- Using the correction as benchmark ground truth.
- An accuracy claim against human outlines. [Q-SCI-17](../docs/OPEN_QUESTIONS.md#q-sci-17) stays open.
- Ruling, pricking, and hair/flesh side. [Q-PRD-10](../docs/OPEN_QUESTIONS.md#q-prd-10) stays open.
- A general TIFF library and a geometry library. [Q-ENG-05](../docs/OPEN_QUESTIONS.md#q-eng-05) and [Q-ENG-04](../docs/OPEN_QUESTIONS.md#q-eng-04) stay open.
- Qt, a network call, and a new runtime dependency.
- Reading `data/`, `scans/`, `real_data/`, or model weights.
- A solver path that reads the BenchmarkLabel store. Project entities do not gain `truth`, `correct_join`, or `original_text`.
- Adding `outline_ids` to `AlgorithmRun`.
