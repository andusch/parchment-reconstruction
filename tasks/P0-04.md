## Title

Confirm the data model: three epistemic classes, producer, StatusEvent negative knowledge, and content-derived ids.

## Phase

P0

## Objective

Check [DATA_MODEL.md](../docs/DATA_MODEL.md) against the resolved model and correct only a sentence that still conflates producer with epistemic class, stores status on a hypothesis row, or uses a random id for a derived artifact.

## Problem

The data model is the glossary every later ticket cites. A leftover status column, a `missing` grapheme status, or a random hypothesis id would make P1 records disagree with the review.

## User or scientific outcome

A scholar can see that a human reading and a machine reading share the class `interpretation` and differ by producer, and that "these do not join" is a `StatusEvent` rather than a deleted row.

## Acceptance criteria

- [x] Epistemic class is exactly `observed`, `interpretation`, or `hypothesis`. Producer is a required separate field, `human`, `machine`, or `imported`, on interpretations and hypotheses.
- [x] Grapheme text status is `human_read`, `unclear`, or `ocr_inferred`. Each is class `interpretation`. `missing` is not a grapheme status. A gap is a `GapRegion` on a page hypothesis.
- [x] Supplied text lives only on `ScholarlyRestoration`, class `hypothesis`, with no `run_id`. `machine` is not a producer of that record.
- [x] An accept decision does not re-type the reading. A reject appends `StatusEvent` `rejected-via-ValidationDecision`. A machine rejection appends `rejected` in the same write as the hypothesis. The hypothesis row has no status column. Current status is the latest event.
- [x] `AssemblyHypothesis` stores `unplaced_fragment_ids`. `contested` is a `StatusEvent`, not a rewritten assembly.
- [x] Derived ids are UUIDv5 over canonical JSON. Random UUIDs are limited to sessions, validation decisions, status events, protocol events, and the `attempt_id` of a non-completed run.
- [x] `fragment_local_mm` repeats ADR-0011: centroid of the establishing outline, `+x` right, `+y` down, millimetres. The citation does not move when the outline is superseded.
- [x] About one day. No project database is created.
