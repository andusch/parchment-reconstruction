## Title

Derive assembly rank inside one run on the physical channel.

## Phase

P4

## Objective

In about one day, derive assembly order when a list is read, without storing rank and without computing a new score.

## Problem

Rank exists only inside `(run, hypothesis_type, channel)` and is not a column. `physical_join_order` in [src/prw/join_rank.py](../src/prw/join_rank.py) orders joins and refuses an assembly. A stored rank, a dropped `contested` row, or a list that mixes assemblies with joins would change the rank rule.

## User or scientific outcome

A benchmark operator can pass assembly rows, their scores, their runs, and their status events, and receive the `physical` order for one completed run.

## Inputs

- The rank paragraph in [DATA_MODEL.md](../docs/DATA_MODEL.md#score-channels).
- [ADR-0003](../docs/adr/0003-evidence-classes-and-ranked-hypotheses.md) and [ADR-0009](../docs/adr/0009-separate-score-channels.md).
- `AssemblyContent` in [src/prw/provenance.py](../src/prw/provenance.py). Scores may be caller-supplied. This ticket does not require [P4-04](P4-04.md).

## Outputs

- A new module, `prw.assembly_rank`, with `physical_assembly_order`.
- The order contains assemblies that have one `physical` score with hypothesis type `assembly`, whose run status is `completed`, and whose latest status is not `invalidated`.
- A higher score is earlier. Equal scores are ordered by the content-derived hypothesis id, ascending bytewise, the same tie break as `physical_join_order`.
- Position in that sequence is the rank. Rank is not written onto the assembly, and it is not an input to the assembly id.
- An assembly whose latest status is `rejected` or `contested` stays in the order.
- An assembly with no status event is refused. An assembly that cites no run is refused. A list that contains a join or a reading is refused. Assemblies from more than one run are refused.
- An assembly from a `failed` or `cancelled` run is omitted. An assembly with no `physical` score of type `assembly` is omitted.

## Epistemic-class impact

no. Rank is a reading order. It does not re-type the assembly and it does not turn rank 1 into the historical page.

- [x] `contested` and `rejected` stay in the order. `invalidated` is omitted. A `failed` run is omitted.
- [x] A missing status event is refused. A join in the list is refused. Two runs in one list are refused.
