# Add the `language` score channel on hypotheses the physical search already admitted.

- Status: In progress
- Phase: P6

[P6-01](P6-01.md) is Done. It closes [Q-SCI-05](../docs/OPEN_QUESTIONS.md#q-sci-05) and [Q-SCI-09](../docs/OPEN_QUESTIONS.md#q-sci-09) and accepts [ADR-0009](../docs/adr/0009-separate-score-channels.md) option 2. Supplied text may be scored only with an explicit label and a recorded treatment. The accepted default sort is a declared weighted sum in the parameter blob. The channels stay stored separately.

[P6-02](P6-02.md) is Done. It implements `admitted_reading_language` version `1` and the unfrozen `language` command. The score is `eligible_nfc_code_point_count` on hypotheses a physical `ScreeningEvent` already admitted. It does not create a join. P6 is not Done.

Remaining implementation work:

- Report language-score quality with the metric in [EVALUATION.md](../docs/EVALUATION.md), not as character error rate. [P6-02](P6-02.md) does not write that report.
- Implement the declared weighted sum in the parameter blob. That implementation includes a benchmark comparison on the frozen fixture. This phase index does not pick weights.
- Propagate calibration uncertainty into `physical` scores. P0 recorded that requirement and did not implement it.

[Q-SCI-06](../docs/OPEN_QUESTIONS.md#q-sci-06) and [Q-SCI-13](../docs/OPEN_QUESTIONS.md#q-sci-13) stay open. They do not block the remaining work above.
