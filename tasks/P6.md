# Add the `language` score channel on hypotheses the physical search already admitted.

- Status: In progress
- Phase: P6

[P6-01](P6-01.md) is Done. It closes [Q-SCI-05](../docs/OPEN_QUESTIONS.md#q-sci-05) and [Q-SCI-09](../docs/OPEN_QUESTIONS.md#q-sci-09) and accepts [ADR-0009](../docs/adr/0009-separate-score-channels.md) option 2. Supplied text may be scored only with an explicit label and a recorded treatment. The accepted default sort is a declared weighted sum in the parameter blob. The channels stay stored separately. The language scorer and the declared sum are not implemented. P6 is not Done.

Remaining implementation work:

- Report language-score quality with the metric in [EVALUATION.md](../docs/EVALUATION.md), not as character error rate.
- Implement the declared weighted sum in the parameter blob. That implementation includes a benchmark comparison on the frozen fixture. This phase index does not pick weights.
- Propagate calibration uncertainty into `physical` scores. P0 recorded that requirement and did not implement it.
