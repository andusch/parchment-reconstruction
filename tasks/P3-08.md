# Task ticket

- Status: Done
- Phase: P3

A **yes** on any stop-and-ask field means the ticket waits until an ADR and an explicit decision exist. Open questions are indexed in [OPEN_QUESTIONS.md](../docs/OPEN_QUESTIONS.md). The glossary is in [DATA_MODEL.md](../docs/DATA_MODEL.md#glossary).

## Title

Expose edge chords, pairwise joins, and join recall through the headless CLI.

## Phase

P3

## Objective

In about one day, call the P3 use cases from the existing console entry point without importing Qt.

## Problem

Core algorithms have to be usable without the GUI. Chord edges, pairwise joins, and join recall are not reachable from the terminal yet. Command names are not a compatibility contract.

## User or scientific outcome

A benchmark operator can, from a terminal, print chord edges for a millimetre outline, print ranked pairwise joins, and write a join-recall report, with no display.

## Inputs

- Use cases from [P3-03](P3-03.md), [P3-04](P3-04.md), [P3-05](P3-05.md), and [P3-07](P3-07.md).
- The CLI from [P2-07](P2-07.md).
- The headless-CLI rule in [ADR-0005](../docs/adr/0005-qt-shell-and-headless-core.md).

## Outputs

- Unfrozen commands that print edges, print ranked joins, or write a recall report.
- The rank command refuses a BenchmarkLabel join file and does not feed labels into the proposer.
- The recall command reads `kind: join` rows only to write the report from [P3-07](P3-07.md). It does not call the proposer with those rows.
- A missing millimetre frame prints a failure and no pose.

## Epistemic-class impact

no. The CLI prints records the use cases already built. It does not relabel a join as observed or as the historical join.

## Stop and ask

Answer each line `yes` or `no`. Any `yes` blocks implementation until a decision exists.

- Changes a public API: no
- Changes the project format: no
- Changes the privacy policy ([SECURITY_AND_PRIVACY.md](../docs/SECURITY_AND_PRIVACY.md)): no
- Changes evidence semantics (text status, epistemic class, or the meaning of a hypothesis): no

## Schema impact

none. The CLI does not write `manifest.json` or `originals/`.

## Algorithm and benchmark impact

none beyond invoking [P3-03](P3-03.md), [P3-04](P3-04.md), and [P3-07](P3-07.md). The edge and rank commands do not read BenchmarkLabel rows. The recall command does not feed those rows into the proposer.

## New dependencies

none. Use the existing standard-library argument parser. No Qt binding.

## Acceptance criteria

- [x] An edge command prints the interpretation edges and their envelope, or a failure with no edge. A non-millimetre outline does not print a chord.
- [x] A rank command prints pairwise joins in the derived `physical` order, or a failure with no pose when calibration is missing. It refuses a BenchmarkLabel join file and does not feed labels into the proposer.
- [x] A recall command writes the comparison only under the caller-supplied `benchmarks/` path and leaves `labels.json` unchanged.
- [x] The process imports no Qt module. Command names are documented as unfrozen.
- [x] About one day. No network call and no worker thread or process.

## Tests

Invoke the CLI on in-memory or temporary-directory fixtures. Cover a millimetre edge printout, a non-millimetre failure with no pose, a rank printout, a refused BenchmarkLabel path on the rank command, and a recall run that writes only a new report under the temporary `benchmarks/` path. No display and no read of `data/`, `scans/`, or `real_data/`.

## Provenance effects

The CLI prints the envelope the use case built, or the report that copied it. It does not invent a second envelope.

## Non-goals

- A GUI. Closing [Q-ENG-06](../docs/OPEN_QUESTIONS.md#q-eng-06). The foreground CLI is not a worker.
- Freezing command names or flags as a public API.
- A command that supersedes an outline. Invalidation stays in [P3-06](P3-06.md).
- A triple-fragment hypothesis type. [Q-SCI-07](../docs/OPEN_QUESTIONS.md#q-sci-07) stays open.
- Hair side, flesh side, ruling, and pricking. [Q-SCI-19](../docs/OPEN_QUESTIONS.md#q-sci-19) and [Q-PRD-10](../docs/OPEN_QUESTIONS.md#q-prd-10) stay open.
- A capacity or performance target. [Q-PRD-07](../docs/OPEN_QUESTIONS.md#q-prd-07) stays open.
- A geometry library. [Q-ENG-04](../docs/OPEN_QUESTIONS.md#q-eng-04) stays open.
- A project directory. [Q-ENG-01](../docs/OPEN_QUESTIONS.md#q-eng-01) stays open.
- Assemblies, a `language` score, channel fusion, and calibration-uncertainty propagation. Uncertainty propagation is a Phase 6 requirement.
- A claim that a printed rank is the historical join on real parchment.
- A network call and a new runtime dependency.
- Reading `data/`, `scans/`, `real_data/`, or model weights.
- A solver path that reads the BenchmarkLabel store. Project entities do not gain `truth`, `correct_join`, or `original_text`.
- Adding `edge_ids` to `AlgorithmRun`.
