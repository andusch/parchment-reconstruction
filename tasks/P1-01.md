## Objective

Deliver the empty `parchment-workbench` package so later tickets can add hashes, frames, ingest, and a CLI on a checked Python 3.12 tree.

## Problem

The repository has no installable package, no lockfile, and no automated checks. [Q-ENG-02](../docs/OPEN_QUESTIONS.md#q-eng-02) blocks `pyproject.toml` until the Python version and layout are chosen.

## User or scientific outcome

A benchmark operator can install the empty workbench package and run the lint, type, and test checks locally and on macOS CI. No scholarly or imaging workflow changes.

## New dependencies

No runtime dependencies.

Build backend: hatchling, MIT, required to build the `src/` layout. The package does not import it.

Dev tools, each MIT, with exact versions in `uv.lock`:

- ruff: lint and format.
- mypy: strict type check of `src`.
- pytest: test runner, including the `slow` marker.
- pre-commit: local git hooks that call those locked tools.

Network use is `uv lock`, `uv sync`, and GitHub Actions installing these tools. That download is approved for this ticket. The package makes no network call.
