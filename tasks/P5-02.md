## Title

Recognize one operator-supplied line image with local PP-OCRv6 medium weights and store Unicode NFC `ocr_inferred` graphemes.

## Phase

P5

## Objective

Add Kraken >= 7.1.0 as the product-facing HTR runtime and a headless recognizer for one line image. Andu approved this implementation on 2026-11-14 (Asia/Hong_Kong) after [ADR-0010](../docs/adr/0010-local-greek-htr-runtime.md) was accepted. This is the first HTR slice. It does not complete P5.

## Problem

[P5-01](P5-01.md) records the runtime and leaves the recognizer unbuilt. An operator cannot run PP-OCRv6 medium on a line image, normalize its NFD output to NFC, or store a machine reading with a `model_hash` of the local weight bytes.

## User or scientific outcome

An operator with the optional `htr` group and a local `medium.safetensors` file can run `prw recognize` on one line image and read a machine interpretation. The stored text is Unicode NFC. The envelope's `model_hash` is the `sha256:` digest of that file. Without the group, or without that file, the command exits with an actionable error and does not download weights.

## Inputs

- [ADR-0010](../docs/adr/0010-local-greek-htr-runtime.md) and [P5-01](P5-01.md).
- An operator-supplied line image. This ticket does not detect lines.
- A local path to `medium.safetensors`. The file stays outside Git and outside CI.
- Operator `script` and `language` tags. The defaults are `Grek` and `grc`. Another tag records a nomen sacrum, an abbreviation, or a mixed-script line.

## Outputs

- The unfrozen command `recognize`.
- `ReadingHypothesis` and `GraphemeHypothesis` rows: text status `ocr_inferred`, epistemic class `interpretation`, producer `machine`.
- A provenance envelope whose `model_hash` is the `sha256:` digest of the local weight bytes, or `absent` when the run used no model.

## Epistemic-class impact

no. A machine reading stays `interpretation`, producer `machine`, text status `ocr_inferred`. Acceptance is not written here and does not re-type a reading. Supplied text stays on a scholarly restoration.

## Schema impact

none. No project directory is written, and there is no migration. In-memory ids are computable where the data model cites the reading id and the grapheme id from each other: the reading id hashes the run id and the reading fields other than `grapheme_ids`, plus the ordered NFC texts. Each grapheme id hashes the run id, that reading id, the zero-based position, and the grapheme content. The position keeps a repeated letter distinct. It is not a line-order index.

## New dependencies

Kraken >= 7.1.0, in the optional `htr` dependency group. It is not in `project.dependencies` and not in `default-groups`.

- Reason: [ADR-0010](../docs/adr/0010-local-greek-htr-runtime.md) names Kraken >= 7.1.0 as the product-facing HTR runtime for local PP-OCRv6 medium weights.
- License: Apache License 2.0. Recorded from the package metadata on PyPI (`License: Apache-2.0` for the kraken package) and from the project's `LICENSE` file, which is the Apache License, Version 2.0 (<https://github.com/mittagessen/kraken/blob/main/LICENSE>, <https://www.apache.org/licenses/LICENSE-2.0>).
- The `htr` group also installs Kraken's dependency tree, including PyTorch. PyTorch is not a direct requirement and is not in the default groups. Its project `LICENSE` is the 3-clause BSD terms at <https://github.com/pytorch/pytorch/blob/main/LICENSE>. CI does not install the group.

A weight download is not approved. Version stays 0.0.0.

## Acceptance criteria

- [x] Kraken >= 7.1.0 is in the optional `htr` group. `project.dependencies` stays empty. `default-groups` stays `dev` and `ui`.
- [x] `prw recognize` runs PP-OCRv6 medium from an operator-supplied local path whose file name is `medium.safetensors`. A missing path, or a file with another name, exits `2` and says that the command does not download weights.
- [x] A missing `htr` group exits `2` and tells the operator to run `uv sync --group htr`.
- [x] Model output is normalized from NFD to NFC before storage. Storage does not strip accents and does not normalize final sigma.
- [x] When a model is used, `model_hash` is the `sha256:` digest of the local weight bytes. The Zenodo MD5 `e3411a453ce3b9e9efae3f8631d85762` is not `model_hash`. A run that uses no model stores `model_hash` `absent`.
- [x] The command accepts an operator-supplied line image. It does not add a line detector.
- [x] Readings store `script` and `language`. Nomina sacra, abbreviations, and mixed-script lines are whatever tags the operator passes, and this slice writes no score. `ocr_inferred`, `interpretation`, and `machine` are unchanged.
- [x] The default test selection passes without Kraken, without torch, and without weights. A live recognizer test is skipped unless the `htr` group and `PRW_HTR_WEIGHTS` are both present. That test does not fetch weights.
- [x] Version stays 0.0.0. No character-error number is reported. This ticket leaves Q-SCI-16, Q-SCI-06, and Q-SCI-13 open. [P5-03](P5-03.md) later closes Q-SCI-16. Q-SCI-06 and Q-SCI-13 stay open.

## Tests

Unit tests cover the NFD-to-NFC adapter, a missing weight path, a missing `htr` group, `model_hash` for local bytes and for no model, and storage of `ocr_inferred` / `interpretation` / `machine`. They use a synthetic TIFF and in-memory text. They do not read `data/`, `scans/`, `real_data/`, TIFF sources from the checkout, or model weights. The live test is skipped unless `PRW_HTR_WEIGHTS` names a local `medium.safetensors` and Kraken imports.

## Provenance effects

A completed or failed recognition writes one envelope: source hash of the line image, the full parameter blob and its `sha256:` digest, algorithm `greek_line_htr` version `1`, `model_hash`, code version, and the TIFF decoder name and version. `random_seed` is omitted. Greedy decoding is treated as deterministic. The parameter blob records the runtime, the model file name, NFC normalization, the script and language tags, and `scored: false`. It is not a hash-only blob.

## Non-goals

- Downloading `medium.safetensors` or any other weight file. Hashing a file that is not on the machine. Treating the Zenodo MD5, or an unofficial Hugging Face LFS digest, as `model_hash`.
- A line detector or a page-to-line segmenter.
- A character-error number for this workbench. The card's 7.21% CER and 44.03% WER stay citations.
- Closing [Q-SCI-16](../docs/OPEN_QUESTIONS.md#q-sci-16), [Q-SCI-06](../docs/OPEN_QUESTIONS.md#q-sci-06), or [Q-SCI-13](../docs/OPEN_QUESTIONS.md#q-sci-13) on this ticket. [P5-03](P5-03.md) later closes Q-SCI-16. Q-SCI-06 and Q-SCI-13 stay open.
- Treating model scores as probabilities, or writing an `htr` or `language` score. P6 language scoring.
- Renaming `ocr_inferred`. A license-server check. A change to the project format, the privacy policy, or evidence semantics.
- Loosening ranker or segmentation checks. Claiming a join or a historical reading.
- Cutting 1951.314, reopening 1999.137, or starting Pilot-12. P6, P7, and P8.
- Committing weights or other large binaries.
