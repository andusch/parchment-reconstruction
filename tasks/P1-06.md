# Task ticket

- Status: Ready
- Phase: P1

A **yes** on any stop-and-ask field means the ticket waits until an ADR and an explicit decision exist. Open questions are indexed in [OPEN_QUESTIONS.md](../docs/OPEN_QUESTIONS.md). The glossary is in [DATA_MODEL.md](../docs/DATA_MODEL.md#glossary).

## Title

Generate synthetic fragment geometry and write ground truth only to the BenchmarkLabel store.

## Phase

P1

## Objective

In about two days, emit a page polygon, cut curves, fragment polygons, and rigid placements for a seeded generator whose named parameters include missing-fragment percentage, edge erosion, and rotation. Ground truth goes under `benchmarks/` and nowhere else.

## Problem

Later phases need a frozen geometric fixture. The evaluation contract, once [P0-05](P0-05.md) is done, requires ADR-0011 coordinates and a BenchmarkLabel home. The package cannot yet generate either. Raster and lighting are a separate ticket so this one stays within two days.

## User or scientific outcome

A benchmark operator can generate one synthetic leaf, read fragment-local coordinates in the ADR-0011 frame, and find joins and placements only in the BenchmarkLabel store.

## Inputs

- The fixture contract written by [P0-05](P0-05.md) in [EVALUATION.md](../docs/EVALUATION.md).
- [ADR-0011](../docs/adr/0011-frame-conventions.md) and the frame helpers from [P1-04](P1-04.md).
- Envelope and id helpers from [P1-02](P1-02.md) and [P1-03](P1-03.md).
- Agent rule 13.

## Outputs

- A generator function that returns polygons, cut curves, join labels, and rigid placements.
- BenchmarkLabel records under a caller-supplied `benchmarks/` directory.
- A parameter blob that includes the geometry parameters and `random_seed`.

## Epistemic-class impact

no. Labels are ground truth for the fixture only. They are not hypothesis rows, not observed readings, and not `correct_join` fields.

## Schema impact

none for the project evidence database. The BenchmarkLabel file is outside that database. Its layout is the evaluation store, not ADR-0007.

## Algorithm and benchmark impact

The generator is new. It writes labels. It does not score a solver and does not edit an existing label to pass a test. Solver code in this ticket does not exist and must not read the store.

## New dependencies

none. Erosion is an inward offset of each vertex toward the fragment centroid by the named fraction. It is not a library buffer.

## Acceptance criteria

- [ ] Parameters are named fields: missing-fragment percentage, edge erosion, and rotation. Lighting is accepted in the blob only as a passthrough for [P1-07](P1-07.md); this ticket does not rasterize it. The blob is canonical JSON. Its hash uses the `sha256:` prefix. `random_seed` is present.
- [ ] The same seed and parameters reproduce the same polygons and the same content-derived label ids.
- [ ] Fragment-local coordinates use the centroid origin, `+x` right, `+y` down, millimetres. Page placements use the same axes in `page_global_mm`.
- [ ] Missing-fragment percentage omits that fraction of pieces from the emitted fragment set. The omission is not grapheme status `missing`.
- [ ] Joins, placements, and the generator page are written only under `benchmarks/`. No project database is created. No field is named `truth`, `correct_join`, or `original_text` on a project entity.
- [ ] About two days. No network call. No geometry library.

## Tests

Synthetic generation in a temporary `benchmarks/` directory. Assert frame axes, seed repeatability, erosion moving a vertex toward the centroid, and that a project-shaped directory is not created. Tests may write the labels. They must not rewrite labels to satisfy an assertion.

## Provenance effects

The generator records the full parameter blob, its `sha256:` hash, algorithm name and version, `model_hash` `absent`, `code_version`, and `random_seed`. Decoder name and version are `absent` until [P1-07](P1-07.md) writes images.

## Non-goals

- Join ranking, outline detection, and any claim about real parchment.
- A geometry library. [Q-ENG-04](../docs/OPEN_QUESTIONS.md#q-eng-04) stays open.
- The ADR-0007 project layout.
