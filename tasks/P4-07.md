# Task ticket

- Status: Ready
- Phase: P4

A **yes** on any stop-and-ask field means the ticket waits until an ADR and an explicit decision exist. Open questions are indexed in [OPEN_QUESTIONS.md](../docs/OPEN_QUESTIONS.md). The glossary is in [DATA_MODEL.md](../docs/DATA_MODEL.md#glossary).

## Title

Expose assembly search, assembly rank, and the two assembly reports through the headless CLI.

## Phase

P4

## Objective

In about one day, call the P4 use cases from the existing console entry point without importing Qt.

## Problem

Core algorithms have to be usable without the GUI. Assembly search, assembly rank, placement error, and end-to-end join presence are not reachable from the terminal yet. Command names are not a compatibility contract.

## User or scientific outcome

A benchmark operator can, from a terminal, print ranked assemblies, print the physical assembly order, and write the two comparison reports, with no display.

## Inputs

- Use cases from [P4-03](P4-03.md), [P4-04](P4-04.md), [P4-05](P4-05.md), and [P4-06](P4-06.md).
- The CLI from [P3-08](P3-08.md) in [src/prw/cli.py](../src/prw/cli.py).
- The headless-CLI rule in [ADR-0005](../docs/adr/0005-qt-shell-and-headless-core.md).

## Outputs

- Unfrozen commands that search assemblies, print the physical assembly order, write a placement-error report, or write an end-to-end join-presence report.
- The search command takes joins, millimetre outlines, a page frame, N, and the two pose tolerances. It refuses a BenchmarkLabel path and does not feed labels into `prw.assembly_search`.
- The rank command prints the physical order from [P4-03](P4-03.md). It refuses a join list and a BenchmarkLabel path.
- The two report commands write only under the caller-supplied `benchmarks/` path. They read `kind: placement` or `kind: join` rows only to write the reports from [P4-05](P4-05.md) and [P4-06](P4-06.md). They do not call the search with those rows.
- A missing page frame, a missing N, or a non-millimetre outline prints a failure and no placement.

## Epistemic-class impact

no. The CLI prints records the use cases already built. It does not relabel an assembly as observed or as the historical page.

## Stop and ask

Answer each line `yes` or `no`. Any `yes` blocks implementation until a decision exists.

- Changes a public API: no
- Changes the project format: no
- Changes the privacy policy ([SECURITY_AND_PRIVACY.md](../docs/SECURITY_AND_PRIVACY.md)): no
- Changes evidence semantics (text status, epistemic class, or the meaning of a hypothesis): no

## Schema impact

none. The CLI does not write `manifest.json` or `originals/`.

## Algorithm and benchmark impact

none beyond invoking [P4-04](P4-04.md), [P4-05](P4-05.md), and [P4-06](P4-06.md). The search and rank commands do not read BenchmarkLabel rows. The report commands do not feed those rows into the search.

## New dependencies

none. Use the existing standard-library argument parser. No Qt binding.

## Acceptance criteria

- [ ] A search command prints the kept assemblies and their physical screening events, or a completed empty list, or a failure with no placement. It refuses a BenchmarkLabel path and does not feed labels into the search.
- [ ] A rank command prints assemblies in the derived `physical` order. It refuses a join in that list.
- [ ] A placement-error command and a join-presence command each write a new report only under the caller-supplied `benchmarks/` path and leave `labels.json` unchanged.
- [ ] The process imports no Qt module. Command names are documented as unfrozen.
- [ ] About one day. No network call and no worker thread or process.

## Tests

Invoke the CLI on in-memory or temporary-directory fixtures. Cover a search printout, a failure with no placement when the page frame is missing, a refused BenchmarkLabel path on the search command, a rank printout, and both report runs writing only a new file under the temporary `benchmarks/` path. No display and no read of `data/`, `scans/`, or `real_data/`.

## Provenance effects

The CLI prints the envelope the search built, or the report that copied it. It does not invent a second envelope.

## Non-goals

- A GUI. Closing [Q-ENG-06](../docs/OPEN_QUESTIONS.md#q-eng-06). The foreground CLI is not a worker.
- Freezing command names or flags as a public API.
- A near-duplicate filter. [Q-SCI-08](../docs/OPEN_QUESTIONS.md#q-sci-08) stays open.
- A face constraint. [Q-PRD-03](../docs/OPEN_QUESTIONS.md#q-prd-03) stays open.
- Accepting [ADR-0008](../docs/adr/0008-rigid-rectangular-page.md). It stays Proposed.
- A `GapRegion`. [Q-SCI-13](../docs/OPEN_QUESTIONS.md#q-sci-13) stays open.
- A triple-fragment hypothesis type. [Q-SCI-07](../docs/OPEN_QUESTIONS.md#q-sci-07) stays open.
- Hair side, flesh side, ruling, and pricking. [Q-SCI-19](../docs/OPEN_QUESTIONS.md#q-sci-19) and [Q-PRD-10](../docs/OPEN_QUESTIONS.md#q-prd-10) stay open.
- A capacity or performance target. [Q-PRD-07](../docs/OPEN_QUESTIONS.md#q-prd-07) stays open.
- A geometry library. [Q-ENG-04](../docs/OPEN_QUESTIONS.md#q-eng-04) stays open.
- A project directory. [Q-ENG-01](../docs/OPEN_QUESTIONS.md#q-eng-01) stays open.
- A `language` score, channel fusion, and calibration-uncertainty propagation. Uncertainty propagation is a Phase 6 requirement.
- A claim that a printed assembly is the historical page on real parchment.
- A network call and a new runtime dependency.
- Reading `data/`, `scans/`, `real_data/`, or model weights.
- A solver path that reads the BenchmarkLabel store. Project entities do not gain `truth`, `correct_join`, or `original_text`.
