# Group A — The epistemic model (Blockers 1–4 + several majors)
The root error: the documents conflated who produced something (human vs. machine) with what kind of thing it is (observation vs. interpretation vs. hypothesis). These are orthogonal axes.

### R1. [FIX] Epistemic classes are exactly three:

observed — physical measurements bound to source bytes (pixels, calibration, fragment extent). Never readings, never placements.
interpretation — readings and measurements derived from observation: OCR readings, human letter readings, detected outlines, detected lines.
hypothesis — reconstruction proposals: joins, assemblies, placements, restorations. A human placing a fragment produces a hypothesis with producer: human, not an observation.


### R2. [FIX] Producer is a separate, required field (human / machine / imported) on every interpretation and hypothesis. A scholar's reading is interpretation + producer: human. Authority differs; evidence class does not. Accepting a machine reading creates a ValidationDecision pointing at it — it never re-types it.

### R3. [FIX] missing is not a grapheme status. Gaps are GapRegion entities (geometry + extent + uncertainty) belonging to a page hypothesis. Remove missing from GraphemeHypothesis.status.

### R4. [FIX] Fragments get identification_status: catalogued (from owner inventory/manifest), detected (machine-proposed), confirmed (human-reviewed detection). Only catalogued/confirmed fragments enter matching by default.

### R5. [FIX] Validation composes by rule: accepting an assembly is blocked if any contained join is rejected; rejecting a join marks all containing assemblies contested. ScholarlyRestoration may only cite non-rejected hypotheses. These are application-service invariants, stated in the data model.

### R6. [FIX] Add negative knowledge: JoinCandidate.status includes rejected (machine) and rejected-via-ValidationDecision (human), and assemblies record unplaced_fragment_ids. "These do not join" and "this was not placed" are first-class records — they're also future training labels.

# Group B — Reproducibility (Blocker 5 + minors)

### R7. [FIX] Every derived artifact stores the full parameter blob (canonical JSON: sorted keys, UTF-8, no insignificant whitespace) plus its SHA-256. Hash-only is not acceptable.

### R8. [FIX] The reproducibility equality condition is: same source hashes + same parameter hash + same algorithm version + same code version + same model hash + same seed ⇒ same ranked hypothesis content. Add code_version (git SHA) to the condition.

### R9. [FIX] Hypothesis IDs are content-derived (e.g., UUIDv5 over run manifest + hypothesis content), so a repeated run reproduces identical IDs. Random UUIDs only for sessions/decisions, never for derived artifacts.

### R10. [FIX] Determinism is guaranteed only for completed runs. Cancelled/failed runs are marked status: cancelled|failed and their partial hypotheses are excluded from reproducibility claims and from ranking.

### R11. [FIX] Checksum failures get an entity: IntegrityFailure (source_id, presented_hash, expected_hash, timestamp). It is recorded as a protocol event — it is not "observed evidence"; it simply never enters the evidence pool. The PRD sentence calling it observed evidence is deleted.

# Group C — Geometry and frames (several majors)

### R12. [FIX] Two transform types: RigidTransform (rotation + translation only — all placements) and CalibrationTransform (similarity, per source image only). A free affine is stored only as a DiagnosticRecord, never used for placement.

### R13. [FIX] One shared page frame per project. PageFrame is project-owned with dimension ranges (min/max width/height); all assemblies place fragments in this shared frame so hypotheses are comparable. CoordinateFrame.parent_frame_id is removed — transforms live on placements/calibrations only; frames are named coordinate systems, not transform storage.

### R14. [FIX] Add EdgeArc as a first-class entity: stable ID scoped to its FragmentOutlineRevision, geometry always in fragment_local_mm. Joins reference edge IDs. Superseding an outline revision invalidates its edges and dependent join candidates (recorded, not deleted).

### R15. [DECIDE] Frame conventions (write as ADR): fragment_local_mm origin at the fragment mask centroid, +x right, +y down (matching image/OpenCV convention to prevent sign bugs), units in millimetres. Same handedness for page_global_mm.

### R16. [FIX] The rectangular page is an explicit assumption with tolerance: dimension ranges, not point values; anisotropic shrinkage and cockling are recorded as open questions (DEFER to the non-rigid phase). Rigid ranking penalties are documented as a known limitation.
